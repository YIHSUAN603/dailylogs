# 日報告 DailyLogs — 安裝與使用指南（Windows）

撰寫工作日報的桌面小工具：每天用 Markdown 記錄做了什麼，一鍵產出可寄送／貼上的格式化日報。資料全存在自己電腦（離線、不上傳）。

---

## 一、安裝

1. 拿到安裝程式 `日報告 DailyLogs_0.1.0_x64-setup.exe`，**雙擊執行**。
2. **可能出現「Windows 已保護您的電腦」藍色視窗**：這是因為程式未做數位簽章，並非病毒。
   點視窗裡的 **「其他資訊」** → 再點 **「仍要執行」** 即可繼續安裝。
3. 若電腦沒有 Microsoft Edge WebView2（Windows 11 內建；部分 Windows 10 沒有），安裝程式會自動引導你裝好，照畫面點「下一步」即可。
4. 安裝完成後，從 **開始選單** 找到 **「日報告 DailyLogs」** 開啟。

---

## 二、第一次開啟

畫面分三塊：

- **左側清單**：日報搜尋框、`+ 今日` 建立按鈕、每筆日報的日期與狀態徽章（**完成** / **草稿**）。
- **右側編輯區**：Markdown 編輯器，左邊打字、右邊即時預覽。
- **左下角**：`📅 週報 / 月報`、`⚙ 設定` 兩個切換鈕。

> **你的資料存在哪？**
> 本機 SQLite 資料庫，路徑：`%APPDATA%\com.richitech.dailylogs\dailylogs.db`
>（在檔案總管網址列貼上 `%APPDATA%\com.richitech.dailylogs` 可直接打開資料夾。）
> 換電腦／重灌前，請先做備份，見〈六、資料備份與換機〉。

---

## 三、每天寫日報

1. 點左上 `+ 今日` 建立當天日報（也可點旁邊的下拉箭頭挑其他日期）。
2. 直接用 **Markdown** 寫今天做了什麼、遇到什麼問題、明天要做什麼。
   可自由使用標題（`#`）、清單（`-`）、表格等語法，右側會即時預覽。
3. **不用按存檔**：停筆約 0.6 秒會自動儲存，狀態列會顯示「儲存中…」→「已儲存 HH:MM:SS」。
4. 寫完想標記為完成，勾選 **`標記完成`**，左側徽章就會從「草稿」變「完成」。
5. 要刪掉當天日報，點 **`刪除`**（會跳確認）。

> 不熟 Markdown 也沒關係：當成純文字一行一行寫即可；編輯器上方有工具列可一鍵套用粗體、清單、標題。

---

## 四、輸出 / 寄送

編輯器下方 **「輸出：」** 區提供幾種方式，選最適合寄送對象的：

| 按鈕 | 用途 |
| --- | --- |
| `複製文字` | 複製成**純文字**（去掉 Markdown 符號）→ 貼進 Teams／LINE／郵件最乾淨 |
| `複製 MD` | 複製**原始 Markdown** → 貼進支援 Markdown 的地方 |
| `存 .md` | 存成 Markdown 檔（預設檔名 `日報_YYYY-MM-DD.md`） |
| `存 Word` | 存成 Word 檔（`.docx`，已套中文字型） |
| `列印 / PDF` | 開啟系統列印視窗；選「另存為 PDF」即可產出 PDF |

---

## 五、週報 / 月報彙整

點左下 `📅 週報 / 月報`：

1. 用快捷鈕選範圍：**本週 / 上週 / 本月 / 上月 / 近 30 天**；或自訂「起／迄」日期後按 `查詢`。
2. 按 `AI 彙整成報告`，把這段期間的多天日報自動彙整成一份（**需先設定好 AI**，見第七節）。
3. 產出的標題與內容都可以再編輯，滿意後按 `💾 儲存到 DB` 存起來。
4. 下方有歷史清單，可點開重新載入、編輯或刪除；同樣能 `複製` / `存 .md` / `列印 / PDF`。

---

## 六、資料備份與換機

點 `⚙ 設定` → 最下方 **「資料備份」**：

- `匯出全部資料`：把所有日報、標籤、彙整報告、設定存成一個 JSON 檔（預設 `日報備份_YYYY-MM-DD.json`）。**換電腦或重灌前務必先做這步。**
- `匯入資料`：在新電腦讀回那個 JSON 檔；**同一天的日報會被覆蓋**。

> ⚠️ 為了安全，TFS 的存取權杖（PAT）**不會**寫進備份檔。換機後若有用 TFS，需要重新填一次（見第八節）。

---

## 七、（選用）啟用 AI 協助

AI 功能是**選用**的，沒設定也能正常寫日報；要用的話，需要在這台電腦先裝好一個可用的 AI 指令工具。

1. 預設指令是 `claude -p`，代表使用 **Claude Code CLI**——需先在電腦安裝它並完成登入。
2. 到 `⚙ 設定` → **「AI 命令」**：
   - 可把指令改成完整路徑（例如安裝在自訂位置時）。
   - `AI 超時秒數` 預設 120，AI 回應較慢時可調大。
   - 按 `測試連線` 驗證是否可用（成功會收到簡短回覆）。
3. 設定好後，編輯器上方會有這些 AI 按鈕：
   - `整理成正式報告`：把零散筆記整理成有結構的日報。
   - `潤稿`：修飾語句、修正錯字，內容不變。
   - `產生標籤`：自動產生 2～5 個分類標籤（顯示成 `#標籤`）。

---

## 八、（選用）TFS 整合：從 commit 草擬日報

如果你的程式碼放在公司 TFS／Azure DevOps，可以讓它自動抓當天的 commit 來草擬日報。

1. 到 `⚙ 設定` → **「TFS 整合」**，填寫：
   - `TFS 位址（含 /tfs）`：例如 `http://192.168.0.143:8080/tfs`
   - `PAT`：個人存取權杖，需具備 **Code（read）** 權限
   - `Collections`：輸入 collection 名稱（例如 `MCollection`），按 `新增`，至少要有一個
   - `作者關鍵字`：例如 `ARIESCHAO`（逗號分隔、不分大小寫、包含比對；留空＝不限作者）
2. 按 `測試連線`，成功會顯示找到幾個 repo。
3. 回到編輯器，點 `從 Git 草擬`：會抓當天的 commit 標題，依 repo 分組附進當天日報（已存在的不會重複）。

---

## 九、常見問題

- **開啟後閃退／一片空白**：多半是缺 WebView2。重新執行安裝程式，或到微軟官網搜尋「WebView2 Runtime」手動安裝後再開。
- **安裝時被 SmartScreen 擋下**：見第一節——點「其他資訊」→「仍要執行」。程式未簽章屬正常，不是病毒。
- **AI 按鈕沒反應或報錯**：通常是 AI 指令工具沒裝好、路徑不對或尚未登入。回 `⚙ 設定 → AI 命令` 用 `測試連線` 排查。
- **TFS 抓不到 commit**：確認 PAT 權限、collection 名稱、作者關鍵字是否正確，並先用 `測試連線` 確認連得上。
